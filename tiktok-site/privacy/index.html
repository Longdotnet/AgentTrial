Privacy Policy

Effective date: October 25, 2026

This Privacy Policy explains how VietSub Series Manager handles information when you use the desktop application and its TikTok integration.

1. Information used by the application

Depending on the features you use, the application may handle:

  • basic TikTok profile information authorized through TikTok Login Kit, such as open ID, display name, and avatar;
  • TikTok authorization tokens needed to use approved API features on your behalf;
  • video publishing metadata such as captions, privacy choices, schedules, publish identifiers, and status;
  • local video files, subtitle files, and processing results selected or generated by you;
  • technical logs required to diagnose processing or publishing failures.

2. Why this information is used

The application uses this information only to provide requested functionality, including:

  • connecting the TikTok account you authorize;
  • showing available TikTok publishing options;
  • preparing, approving, scheduling, and publishing user-authorized video content;
  • checking publishing status and displaying errors;
  • maintaining the local processing queue and application state.

3. Local storage

VietSub Series Manager is primarily a desktop application. Application state, processing files, publishing metadata, and logs are stored locally on the user's computer. On Windows, application runtime data is stored under the user's local application data directory.

4. TikTok credentials and tokens

TikTok developer credentials and user authorization tokens are stored using the Windows Credential Manager rather than in the application's SQLite processing database. Tokens are used only to perform actions that the user has authorized through TikTok.

5. Website data

This public informational website is static. It does not provide account registration and does not intentionally use advertising trackers, analytics cookies, or behavioral profiling. The hosting provider may process ordinary technical request information such as IP address, browser type, and request logs as part of hosting and security.

6. Sharing of information

Information is sent to TikTok only when necessary to perform a TikTok feature requested by the user, such as account authorization, creator information lookup, video upload, publishing, or status checking. We do not sell personal information.

7. Retention

Local processing records remain on the user's device until they are removed by the user or by application data maintenance. TikTok authorization tokens remain available until they expire, are replaced, are revoked, or the user disconnects access.

8. Revoking TikTok access

Users can revoke the application's access through their TikTok account settings and connected-app controls. After access is revoked, API features requiring TikTok authorization will no longer function until the user authorizes the application again.

9. Security

The application uses local OS credential storage for sensitive TikTok credentials and tokens, applies explicit approval before publishing, and records publishing state to reduce accidental duplicate operations. No method of storage or transmission is guaranteed to be completely secure.

10. Children's privacy

VietSub Series Manager is not designed to knowingly collect personal information from children through this website. TikTok account eligibility and age requirements are governed by TikTok's own rules.

11. Changes to this policy

This policy may be updated when application behavior or third-party integrations materially change. The effective date above will be updated when a revised policy is published.

12. Contact

Privacy questions can be raised through the support contact associated with the VietSub Series Manager developer listing.
